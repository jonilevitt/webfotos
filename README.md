# Estudio Joni Levit

Home de prueba, estática y adaptable a celular. HTML y CSS, sin instalación ni compilación.

Para verla localmente: `python3 -m http.server 8000` y abrir http://localhost:8000.

Para publicar en GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Las fotografías de muestra se cargan desde Unsplash y las tipografías desde Google Fonts; necesitan conexión a internet. Las imágenes no se presentan como trabajos del estudio. Reemplazarlas por fotografías propias antes de usar la web como portfolio definitivo.
